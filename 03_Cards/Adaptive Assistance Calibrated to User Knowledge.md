# Adaptive Assistance Calibrated to User Knowledge

## One-Line Summary
Over time, AI assistants should need fewer instructions from users — the system should calibrate its guidance, explanations, and prompting style to what the user already knows and has demonstrated.

## Motivation
Today's AI assistants treat every interaction as a fresh start. Expert users receive the same verbose explanations as novices. Over time, users develop preferences, expertise, and interaction styles that should inform how AI assists them — reducing friction and increasing efficiency.

## Research Questions
| # | Question |
|---|----------|
| RQ1 | How do users' interaction patterns with AI evolve over time as they gain expertise? |
| RQ2 | Can AI systems infer user knowledge level from interaction history and adapt accordingly? |
| RQ3 | Does adaptive guidance improve task performance and satisfaction vs. static guidance? |
| RQ4 | How do users react to AI systems that make incorrect assumptions about their knowledge? |

## Variables
**Independent:** Adaptation condition (adaptive vs. static), Time / experience
**Dependent:** Task performance, satisfaction, interaction efficiency, user frustration
**User variable:** Prior knowledge, AI experience

## Study Design
- **Longitudinal:** Track users over multiple sessions; measure adaptation quality
- **Controlled experiment:** Adaptive vs. static assistance on matched tasks
