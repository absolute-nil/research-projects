# Biased Information Foraging and Echo Chambers

## Problem
Conversational AI changes information foraging from browsing discrete documents to interacting with a responsive agent. This can make confirmatory search easier, make subjective queries feel natural, and cause neutral systems to accommodate users' biases.

## Why It Matters
If conversational search amplifies confirmation bias, it can polarize users even without an explicitly biased system. Voice, personalization, citations, and agent confidence may further shift susceptibility.

## My Angle
I study this from the user's side: how people seek, consume, trust, verify, and revise beliefs when the information interface is conversational.

## Mechanisms
- User fingerprint: bias, language, topic familiarity, time sensitivity, trust, over-reliance.
- Agent behavior: suggestions, interface, modality, search vs conversation, response framing.
- Information flow: seeking -> consumption -> trust -> feedback -> dissemination.
