# Limit Users to 3 LLM Turns + Countdown

## One-Line Summary
Experimental manipulation constraining users to a maximum of 3 turns with an LLM (with a visible countdown), forcing more deliberate and strategic query behavior.

## Motivation
Unlimited conversational turns may encourage lazy or exploratory search without commitment. A hard limit (with visible countdown) forces users to think carefully about what they ask — potentially improving query quality and deliberation.

## Design Notes
- Visible countdown counter shown to user
- Limit: 3 turns per session or per topic
- Compare to unlimited turn condition on: query quality, deliberation, task success, information quality

## Research Questions
| # | Question |
|---|----------|
| RQ1 | Does a turn limit cause more deliberate (higher quality) queries? |
| RQ2 | Does the limit reduce or increase user satisfaction? |
| RQ3 | Does performance differ between limited and unlimited users? |
