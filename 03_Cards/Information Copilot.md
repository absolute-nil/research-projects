# Information Copilot

## Working Definition
An information copilot is a conversational system that helps users seek, compare, verify, contextualize, and disseminate information while preserving common ground and making uncertainty visible.

## Distinction
This is not only an answer engine. It should support source inspection, perspective comparison, clarification, correction, and feedback.
