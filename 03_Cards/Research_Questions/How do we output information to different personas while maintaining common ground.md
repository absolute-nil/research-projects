# How do we output information to different personas while maintaining common ground?

## Why It Matters
Personalization can make information more accessible, but it can also fracture shared reality if each user receives a different evidentiary frame.

## Candidate Operationalization
- Compare personalized explanations against a shared common-ground layer.
- Measure comprehension, trust, source recall, and disagreement quality.
- Test whether persona-specific framing changes evidence weighting.
