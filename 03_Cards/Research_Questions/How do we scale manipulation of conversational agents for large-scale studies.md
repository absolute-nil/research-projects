# How do we scale manipulation of conversational agents for large-scale studies?

## Why It Matters
Many studies need controlled changes to retrieval, voice, persona, uncertainty, citations, and interface state. Without reusable infrastructure, each study becomes a custom software project.

## Candidate Operationalization
- Define configurable variables for agent behavior, retrieval, interface, modality, and logging.
- Build reusable study flows and condition assignment.
- Evaluate whether researchers can create reliable manipulations without custom engineering.
