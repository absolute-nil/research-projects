# User Fingerprint

## Definition
A user fingerprint is the set of traits, constraints, and situational factors that shape how a person interprets, trusts, seeks, and verifies AI-mediated information.

## Candidate Dimensions
- Language and language familiarity.
- Topic familiarity.
- Prior beliefs and bias.
- Time sensitivity and cognitive load.
- Trust in the agent.
- Over-reliance tendency.
- Modality preference and accessibility needs.

## Research Use
Use fingerprints to explain why the same information signal can help one user and mislead another.
