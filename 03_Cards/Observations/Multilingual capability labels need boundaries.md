# Multilingual capability labels need boundaries

## Observation
Calling a system multilingual can hide whether it actually supports a user's language, topic, community context, and information need.

## Why It Matters
Capability labels should specify boundaries: what tasks, languages, domains, cultural contexts, and harms are covered.
