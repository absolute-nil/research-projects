# Prompt engineering as interface failure

## Observation
If average users must learn a hidden prompt language to make LLMs behave well, the interface is shifting cognitive work to users instead of making model constraints and affordances legible.

## Why It Matters
This connects mixed-initiative collaboration to interface design: a good collaborator should surface constraints, ask clarifying questions, and translate user goals into actionable context.
