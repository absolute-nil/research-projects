# User behavior is affordance-dependent

## Observation
User behavior is not fixed; it changes with model capabilities, interface affordances, context, social norms, and the surrounding information environment.

## Why It Might Matter
This limits what user simulation can promise. Simulations may help prioritize studies, but they cannot permanently predict behavior in a changing sociotechnical environment.

## Evidence / Context
- The draft argues that both model behavior and user behavior are fluid.
- It frames user simulation as useful for informed decision-making about affordances, not as a final substitute for empirical testing.
