# Generative Echo Chamber Effect in Voice-Based Conversational Search

## One-Line Summary
Voice modality may amplify users' cognitive susceptibility to AI-generated misinformation compared to text — this study measures that effect and tests existing/new solutions.

## Motivation
Users already over-rely on LLMs in text. Voice adds: lower cognitive load, increased LLM expressiveness, and multi-task environments where users can't check sources. Together, these may supercharge the **Generative Echo Chamber** effect.

## Research Questions
| # | Question | Type |
|---|----------|------|
| RQ1 | How does cognitive susceptibility change in voice vs. text conversational search? | Comparative |
| RQ2 | Does topic familiarity moderate this effect? | Moderator |
| RQ3 | Does a cognitively depleted environment (passive task) exacerbate susceptibility? | Moderator |
| RQ4 | Which current over-reliance solutions transfer to voice modality? | Evaluative |
| RQ5 | What new solutions are needed? | Design |

## Variables
**Independent:** Modality (voice/text), Environment (active/passive), Topic familiarity, LLM uncertainty verbalization
**Dependent:** Cognitive susceptibility, trust, polarization/belief change
**Mediator:** Trust
**Moderators:** Topic bias, topic familiarity, environment

## Study Design
- **Type:** Controlled experiment (2x2 factorial minimum)
- **Participants:** General population / MTurk / Prolific
- **Task:** Information seeking on contested topics (politics, health) via voice vs. text agent
- **Passive condition:** Secondary task (driving sim, game) during voice interaction
- **Measures:** Pre/post belief change, trust scales, think-aloud, interaction logs
