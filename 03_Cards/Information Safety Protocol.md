# Information Safety Protocol

## Working Definition
An information safety protocol specifies how conversational agents should handle evidence, uncertainty, missing information, contested claims, inference risk, and user oversight across seeking, consumption, and dissemination.

## Candidate Requirements
- Mark what is known, uncertain, contested, and missing.
- Separate stated evidence from plausible inference.
- Provide source diversity and citation sufficiency signals.
- Support user inspection without overwhelming the user.
- Include repair behavior when the user asks from a false premise.
