# Do Users Notice AI Getting Worse?

## One-Line Summary
Longitudinal or comparative study on whether users detect model degradation (quality drops, slower responses, increased errors) over time or across model versions.

## Motivation
AI companies routinely update models, sometimes trading capability for cost. Users may be exposed to worse models without knowing it. If users can't detect degradation, this creates an accountability gap — and a dark pattern opportunity.

## Research Questions
| # | Question |
|---|----------|
| RQ1 | Can users detect when an AI model has been degraded (objectively worse outputs)? |
| RQ2 | What signals do users use to calibrate their perception of AI quality? |
| RQ3 | Does detection ability vary with user expertise, task type, or AI literacy? |
| RQ4 | How does unnoticed degradation affect user trust over time? |

## Variables
**Independent:** Model quality (high/degraded), Modality, User expertise
**Dependent:** Detection accuracy, trust ratings, task performance, satisfaction

## Study Design
- **Option A:** Comparative experiment — same task, different model versions, measure user detection
- **Option B:** Longitudinal field study — users interact with AI over weeks, model quality changes
- **Option C:** Vignette study — users rate AI responses of varying quality without knowing the manipulation
