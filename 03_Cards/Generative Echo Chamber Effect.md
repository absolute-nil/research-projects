# Generative Echo Chamber Effect

## 💡 Core Insight
When users interact with confirmatory AI — an LLM that selectively reinforces their existing beliefs — they become more polarized, not less. Unlike filter bubbles (passive curation), this is an *active* generative effect: the AI produces novel, fluent, personalized content that amplifies the user's prior stance.

## 🔥 Why It Matters
This is the central mechanism in the [[Voice Echo Chamber — Cognitive Susceptibility]] project. Voice modality may supercharge this effect via: decreased cognitive load, increased LLM expressiveness (tone, pace, emotion), and passive environments where users can't verify sources.

## ❓ Open Questions
- Does voice modality amplify the effect more than environment (active/passive)?
- Is topic familiarity a moderator or a confounder?
- Can any existing solution (uncertainty verbalization, citations, diverse perspectives) break the effect in voice?
