# Web Search vs Parametric Knowledge Choice

## One-Line Summary
Study how users decide when to enable web search vs. rely on a model's parametric (baked-in) knowledge, based on task type, information freshness needs, and trust.

## Motivation
LLMs with optional web search tools (e.g., ChatGPT, Perplexity) give users an explicit choice: use real-time web retrieval or trust the model's training knowledge. This choice point is a novel and understudied behavior in information seeking — it reveals how users reason about AI knowledge limitations.

## Research Questions
| # | Question |
|---|----------|
| RQ1 | For what task types do users prefer web search vs. parametric knowledge? |
| RQ2 | What user mental models drive this choice (freshness, trustworthiness, task difficulty)? |
| RQ3 | Does the choice vary with users' AI literacy or prior experience? |
| RQ4 | When users make the "wrong" choice (e.g., rely on stale parametric knowledge), what are the downstream effects? |

## Variables
**Independent:** Task type (time-sensitive/evergreen, factual/creative, high-stakes/low-stakes)
**Dependent:** Tool choice (search vs. parametric), accuracy of resulting information, satisfaction
**Moderator:** AI literacy, trust in AI

## Study Design
- **Type:** Mixed-method (behavioral log analysis + interview / think-aloud)
- **Platform:** LLM interface with toggle for web search
- **Tasks:** Varied by freshness, difficulty, stakes
