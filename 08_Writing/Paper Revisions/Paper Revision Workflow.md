# Paper Revision Workflow

## Purpose
Store comments, section-level revisions, decisions, and response text in a way that AI agents and future-you can audit later.

## Recommended Structure
Create one folder per paper inside `08_Writing/Paper Revisions`:

```text
Paper Title/
  Revision Log.md
  Section — Introduction.md
  Section — Related Work.md
  Section — Methods.md
  Section — Results.md
  Section — Discussion.md
  Reviewer Comments.md
  Response Plan.md
```

## Section Note Pattern
Each section note should keep:
- Current section goal.
- Original text or link to source.
- Reviewer / advisor comments.
- Revised version.
- Open risks.
- Links to supporting projects, papers, and claims.

## Agentic Writing Rule
Agents should revise from the local section note and cite which comment or decision motivated each change.
