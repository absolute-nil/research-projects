# AlpacaFarm — Simulation Framework for Human Feedback

## One-Sentence Takeaway
Simulation can reduce the cost of developing feedback-learning methods when simulator rankings are validated against human data.

## Why I Care
This is the strongest "utility without perfect realism" example: simulation is useful because it speeds iteration, not because it fully replaces humans.
