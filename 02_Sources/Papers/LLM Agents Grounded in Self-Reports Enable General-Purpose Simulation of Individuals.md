# LLM Agents Grounded in Self-Reports Enable General-Purpose Simulation of Individuals

## One-Sentence Takeaway
Rich self-report data from interviews and surveys can improve person-specific simulation across multiple outcomes.

## Why I Care
This is the strongest "realism / grounding" direction to contrast against the MSR hypothesis-generator approach.

## Open Question
If a simulator needs rich person-specific self-report data to be credible, what can low-cost generic simulators responsibly claim?
