# BASES — Large-scale Web Search User Simulation

## One-Sentence Takeaway
LLM-based agents can generate large-scale web-search behavior with synthetic user profiles, supporting search-behavior modeling when real user data is scarce or private.

## Why I Care
This is closest to information seeking and Gricea. It suggests a path for generating search/conversational traces, but the MSR project needs stronger validation and behavioral scoping.
