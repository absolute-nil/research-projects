# Echo Chamber — RL Post-Training Amplifies Behaviors

## Why It Belongs Here
The paper supports the concern that post-training can amplify echo-chamber behaviors learned from pretraining, which matters for both model behavior and user susceptibility.

## Use In My Work
- Support [[Generative Echo Chamber Effect]].
- Use when discussing system-side amplification rather than only user-side bias.
