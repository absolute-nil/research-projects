# LLMs Get Lost in Multi-Turn Conversations

## Why It Belongs Here
If multi-turn performance degrades, then collaboration cannot be evaluated only with single-turn benchmarks or static preference pairs.

## Use In My Work
- Support [[How do we distinguish completion delegation and collaboration]].
- Inform Gricea logging requirements for long-context and multi-turn interaction failures.
- Use as motivation for repair, common ground, and state tracking.
