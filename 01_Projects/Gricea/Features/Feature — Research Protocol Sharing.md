# Feature — Research Protocol Sharing

## User Need
Researchers should be able to reuse and inspect study designs without copying private data or undocumented implementation details.

## Requirements
- Export protocol, condition schema, prompts, retrieval configuration, measures, and analysis plan.
- Separate public study artifacts from participant data.
- Include version history for protocol changes.
- Support citation and reuse metadata.

## Open Questions
- [ ] What should be public by default?
- [ ] How should community-contributed protocols be reviewed?
- [ ] Can protocols link back to Zotero papers and Obsidian source notes?
