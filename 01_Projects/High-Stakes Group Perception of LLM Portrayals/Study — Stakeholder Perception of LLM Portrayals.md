# Study: Stakeholder Perception of LLM Portrayals

## Decision This Study Enables
Whether stakeholder feedback can improve LLM portrayals of divisive issues without collapsing into false balance or legitimizing extremist positions.

## Research Questions
| ID | Question | Construct | Analysis |
|---|---|---|---|
| RQ1 | How do affected groups judge LLM portrayals of issues where they have stakes? | satisfaction / representation | group comparison |
| RQ2 | Does stakeholder feedback change model outputs? | output shift | qualitative + metric comparison |
| RQ3 | Are feedback-conditioned outputs viewed as more representative by in-groups and out-groups? | perceived parity | mixed effects / qualitative coding |

## Design
| Element | Plan |
|---|---|
| Design | two-phase stakeholder evaluation |
| Participants | in-group and out-group stakeholders for selected topics |
| Conditions | baseline LLM response vs feedback-conditioned response |
| Task | rate and critique responses to issue queries |
| Primary outcome | satisfaction / representativeness parity |

## Measures
- Truthfulness
- Objectivity
- Representativeness
- Diversity
- Relevance / informativeness
- Cognitive load
- Perceived bias
- Clarity
- Suggested changes

## Risks
- Ethics / privacy: stakeholder identity and political views are sensitive.
- Validity: "stake" is not binary and can be difficult to classify.
- Normative risk: some perspectives should not be included merely for balance.
